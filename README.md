# gobanners-orcamento-site

Site estático do chat de orçamento da GoBanners (`atendimento.gobanners.com.br`), publicado pela Hostinger a partir deste repositório (deploy automático a cada push em `main`).

Estrutura (igual ao `rvb-orcamento-site`):
- `index.html` — chat de orçamento (hoje: página "em breve" até o fluxo da GoBanners ficar pronto)
- `painel/` — painel da equipe (login @gobanners.com.br)
- `fotos-agente/` — catálogo de fotos que o agente envia

O código-fonte e as funções ficam em `gobanners-orcamento` (Supabase). Este repositório só recebe o que é publicado.
